# Examples

This directory contains parser grammars, C/Cwhip consumers, a calculator,
expression and statement compilers, and a SmallC frontend/CVM assembly compiler.
Generated parsers are build artifacts, not checked-in sources.

See [Examples](../doc/EXAMPLES.md) for runnable workflows,
[Expression compiler](../doc/EXPRESSION-COMPILER.md) and
[SmallC](../doc/SMALLC.md) for application guides, and
[Visitors](../doc/VISITORS.md) for parser integration.
